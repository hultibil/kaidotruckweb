# KAIDO TRUCK WEB

## 1. Giới thiệu

KAIDO TRUCK WEB là dự án website được xây dựng bằng PHP, HTML, CSS và JavaScript, sử dụng MySQL để quản lý dữ liệu.

Dự án được phát triển và chạy trên môi trường XAMPP.

## 3. Mô tả các thư mục

| Thư mục | Nội dung |
|---|---|
| `admin` | Các file liên quan đến khu vực quản trị và quản lý sản phẩm. |
| `Blog` | Khu vực blog của website. |
| `css` | Chứa các file CSS dùng để thiết kế giao diện. |
| `donhang` | Chứa các file xử lý và hiển thị đơn hàng, lịch sử, theo dõi và trạng thái đơn hàng. |
| `font` | Chứa tài nguyên phông chữ. |
| `Giohang` | Chứa các file liên quan đến giỏ hàng và đặt hàng. |
| `image` | Chứa hình ảnh của website. |
| `js` | Chứa các file JavaScript. |
| `khac` | Chứa các trang HTML khác. |
| `kythuat` | Chứa các trang liên quan đến chi tiết kỹ thuật. |
| `sanpham` | Chứa các trang cửa hàng và chi tiết sản phẩm. |
| `sound` | Chứa tài nguyên âm thanh. |
| `Taikhoan` | Chứa các file đăng ký, đăng nhập, đăng xuất và quản lý tài khoản. |
| `video` | Chứa tài nguyên video. |

## 4. Mô tả một số file chính

| File | Vai trò |
|---|---|
| `db.php` | File kết nối cơ sở dữ liệu. |
| `index.php` | Trang chính của website. |
| `tienich.html` | Trang tiện ích. |
| `gamemini.html` | Trang trò chơi mini. |
| `hoithem.html` | Trang HTML bổ sung. |
| `phpinfo.php` | Trang hiển thị thông tin cấu hình PHP. |
| `README.md` | Tài liệu mô tả dự án và cấu trúc thư mục. |

## 5. Ghi chú

- Các file có hậu tố `_cu` được giữ nguyên tên như trong cấu trúc hiện tại; cần kiểm tra mã nguồn để xác định chức năng cụ thể.
- Các mô tả chức năng trong tài liệu được suy ra từ tên thư mục và tên file.
- Tài liệu này chỉ mô tả cấu trúc thư mục, không khẳng định toàn bộ chức năng đã hoàn thiện.
- Khi thêm hoặc chỉnh sửa chức năng, cần kiểm tra các file liên quan và giữ nguyên cấu trúc hiện có nếu không có yêu cầu thay đổi.
